### 第 3 回合：黑屏修復與便利商店「必須親自走到門口」
- **使用者反饋**：
  - 「銀幕黑頻 要去便利商店買東西需要實際走到該位置」
- **診斷與修正**：
  - **黑屏原因**：
    1. 外部 cdnjs CDN 在部分校園或個人網路環境連線逾時。
    2. Safari / 舊版 Chrome Canvas 沒有 `ctx.roundRect()` 造成渲染中斷。
    3. 相機初始位置曾穿模到地底。
  - **解法**：本地封裝 `assets/three.min.js`，實裝安全 Canvas 圓角 Polyfill。
  - **實體步行**：禁止隨意開啟超商，設定全家入口座標，距離小於 5 公尺才播放「叮咚」進門鈴聲並解鎖選單；若在遠處點擊則以 Toast 顯示剩餘距離並導引。
