## 🚫 二、 使用者痛點與核心設計禁忌 (CRITICAL RULES)

接續的 AI 在開發新功能時，**必須恪守以下 4 大鐵則**：

### 1. 絕不允許死機白屏或報錯（雙引擎相容性架構）
- **發生過的 Bug**：在部分使用者的 Mac Safari 或關閉硬體加速的瀏覽器中，WebGL 會擲出例外，若程式直接中斷會導致畫面一片空白。
- **目前的架構解決方案**：
  - 專案已實裝**「雙核心引擎（Dual-Engine）」**：
    - **第 1 核心**：Three.js 3D 引擎（WebGL 硬體加速，平滑俯瞰與模型動畫）。
    - **第 2 核心**：2.5D Canvas 萬能高相容引擎（純 HTML5 Canvas 2D 向量繪製，不論任何裝置或限制都能 60FPS 順暢執行）。
  - 當 WebGL 偵測不可用或初始化失敗時，系統會**自動、無縫、無感地切換到 2.5D Canvas 模式**，維持相同的地圖座標、操作手感、對話選單與多人連線，**絕不拋出錯誤阻斷遊戲！**
  - 背景色必須始終保持深色夜景（`#07152d`），禁止使用純白背景。

### 2. 禁止在 HUD 底部放置直達商店的按鈕（必須透過探索與地圖）
- **使用者明確糾正**：
  > 「下面『全家超商』這些呈現方式，我並不希望是現在這樣子：
  > 1. 全家超商：要自己去找或者看地圖。我們有一張雙北捷運的地圖，在雙北各個地方都可以找到。
  > 2. 夜市美食：也是一樣，要自己去找或看地圖過去。
  > 3. 情報站：要到特定的地點、找某些特定官員，或是發生特定的事情才可以觸發。」
- **實作規範**：
  - HUD 底部只保留經典 4 顆 Cyberpunk 風格按鈕：`[🎒 背包]`、`[📋 任務]`、`[📍 地圖]`、`[⚙️ 設定]`。
  - 玩家必須點擊 `[📍 地圖]` 打開 **「雙北捷運路網與探索地圖」**，搭乘捷運抵達中山、台北車站、雙連夜市、淡水八里、信義區或北投。
  - 抵達該站點後，玩家必須**在 3D/2.5D 街區中親自走動尋找**超商門市、夜市小吃攤或景點。

### 3. 情報站 (TIB / CCTV) 必須有特定解鎖條件
- 情報站不是隨便點一下就能看的控制台。
- 必須親自搭捷運前往 **北投分局**，走到警車或派出所與 **「林巡官 / 偵查隊長」** 現場會面交談，或拾獲站前暗號紙條觸發事件後，才能調閱 4 分割 CCTV 監視器畫面與悠遊卡進出站時序。

### 4. 體力耗盡機制 (體力不支)
- 長時間跑步會逐漸消耗體力。當體力低於 18 時，會跳出中央警報橫幅「⚠️ 體力不支」，速度減慢，玩家必須尋找長椅休息或飲水/手搖飲恢復。

## 🔄 四、 接續 AI 的 Review 與工作流程指南

當新的 AI Agent 取得此倉庫時，請遵循以下標準作業程序：

1. **環境檢查與啟動**：
   ```bash
   git status
   npm start # 啟動 local WebSocket 私服器與 HTTP (http://localhost:3000)
   ```
2. **驗證雙引擎運作**：
   - 開啟 `index.html`，檢查右上角 `[⚙️ 設定]` 中的「渲染核心模式」：
     - 若支援 WebGL 則顯示 `3D WebGL 硬體加速模式`。
     - 若不支援 WebGL 則顯示 `2.5D Canvas 萬能相容模式`。
   - 測試鍵盤 [WASD] / 手機十字鍵，確認小偵探移動與腿部步行動畫皆正常運作。
3. **驗證捷運探索機制**：
   - 點擊右下角 `[📍 地圖]`，檢查是否包含中山站、台北車站、雙連站（寧夏夜市）、淡水八里、信義區、北投公園。
   - 點擊搭乘捷運扣款 $20，確認角色平滑傳送至該區，且可以在該區自行尋找全家便利商店與各項事件。
4. **驗證情報站觸發**：
   - 走到北投分局警車旁（或捷運站長室），確認唯有抵達現場方可解鎖 CCTV 四分割監視器與悠遊卡比對。
5. **程式碼修改與 Push 規範**：
   - 任何改動前請先執行 `node -c game.js` 確保無語法錯誤。
   - 完成修改後使用 git 提交並 push 至 `origin main`，GitHub Pages 會自動觸發部署。
   - 保持本文件的最新更新。
