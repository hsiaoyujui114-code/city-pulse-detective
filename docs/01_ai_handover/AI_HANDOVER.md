## 🚫 二、 使用者痛點與核心設計禁忌 (CRITICAL RULES)

接續的 AI 在開發新功能時，**必須恪守以下 6 大鐵則**：

### 1. 🈲 嚴格禁用「少年偵探」稱號
- 使用者明確表達**非常不喜歡**這個稱呼！
- 所有程式碼、介面標籤、NPC 暱稱、伺服器廣播、對話框與文檔，**一律稱呼為「都會調查員」或「市民」**。

### 2. 🈲 嚴格禁用「藝碩／益碩」稱謂（永久最高絕對禁忌）
- 委託人明確下達絕對指令：「就算改成什麼市民的，我希望不要有『藝碩』，什麼市民藝碩、什麼都會教授藝碩的，我都不要『藝碩』這個名字。其他人的名字我無所謂，但千萬不要用『藝碩』！」
- 無論是市民、同儕、教授、組員、案件關係人、NPC、代碼變數或文件，全域 100% 嚴格禁止使用「藝碩／益碩」這個名字！

### 3. 🈲 地圖嚴禁點擊直接傳送（真實交通法則）
- 地圖僅供查閱全雙北路網、站牌位置與轉乘路線規劃。
- **嚴格禁止點擊地圖直接瞬移！** 玩家必須親自走到忠孝專用道或中山路邊站牌搭乘公車，或走進捷運出入口。

### 4. 🚌 公車通勤為主軸 ✕ 快轉自由選配（可快轉、亦可隨車慢活觀光、自由下車）
- 以台北市運量之王 **307 幹線公車** 為通勤主軸。
- 登上公車或捷運後，出現交通 HUD，提供兩大彈性模式：
  - **⏩ 快轉過場**：點擊 `[⏩ 快轉過場動畫 (空拍鳥瞰)]`，鏡頭平滑拉高至高空衛星全景快速穿梭於雙北真實路網，抵達目的地後平滑降回地面完成下車。
  - **🚶 隨車漫遊與自由下車**：不點快轉時，玩家隨車平穩漫遊欣賞雙北街景；任何時候皆可點擊 `[🚶 到站下車]` 隨時下車至路側人行道，恢復自由步行。

### 5. 🏃 雙速移動衝刺系統 (走路 ✕ 奔跑)
- **🚶 走路 (Walk)**：速度 0.38，動作自然平滑。
- **🏃 奔跑 (Run / Sprint)**：速度 0.75！支援鍵盤按住 **[Shift]** 或點擊畫面 **`[🏃 奔跑模式]`** 衝刺，腳底伴隨白色氣流特效。
- **🛹 電動滑板 (Skateboard)**：超商購買後速度提升至 1.10，疾馳全地圖。

### 6. 🏪 連鎖品牌實體門市（多據點分佈，全場絕非單一孤店）
- **絕非全場僅有一間門市**！依循雙北真實繁榮商圈，配置完整的連鎖門市網路：
  - **CoCo 都可 (3處)**：中山北路門市、站前南陽店、重慶書店街店（亮橘波浪招牌、微笑標誌、木吧檯茶桶）。
  - **全家 FamilyMart (3處)**：中山北路店、站前館前店、建成圓環店（藍綠雙色燈箱、自動門、茶葉蛋蒸煮）。
  - **7-Eleven 統一超商 (3處)**：站前忠孝店、重慶南路店、中山南京店（經典橘綠紅三色條紋燈箱、御飯糰、CITY CAFE 拿鐵）。

### 7. 🛡️ 現代 2D ✕ 2.5D 動漫都會冒險引擎 (零白屏保證)
- 採用 HTML5 Canvas 向量渲染配合 **Y-Sorting 深度排序**，人物經過建築與路樹前方或後方時具有精確的遮蔽感與地面陰影。
- 頂部懸浮市民大道高架橋，投射立體陰影。
- **100% 跨裝置相容**，在任何老舊電腦、Chromebook、iPad、手機皆保證零白屏、60FPS 秒開！

### 7. 📦 實境解謎遊戲盒 ✕ 虛擬線上雙軌連動 (ARG Mystery Box & QR Entry)
- **實境盒 8 大配件**：手繪大地圖、時空透光硫酸紙、4大仿真證物袋（307打洞車票、花圃便條、超商減塑收據、撕碎草稿）、紅色光學濾鏡卡、雙層密碼旋轉盤、三位數旋轉密碼木盒與環保帆布袋。
- **雙軌連動法則**：
  - **現實實境線**：輕量化設計（3~4 關核心地標：M6 出口、307 專用道站島、館前超商、站前花圃），注重實物觸感與走訪安全，無繁重關卡負擔。
  - **虛擬線上線**：盒內隨附「調查員專屬悠遊卡 / QR Code」秒開免安裝網頁遊戲，體驗大雙北完整路網、公車隨車慢活/快轉、CCTV 時空軌跡與多人破案。

### 8. 🗺️ 雙北地圖 1:1 還原現實拓撲（對齊 Google Maps / OSM，拒絕 RPG Maker 死板方塊）
- 視角：2D / 2.5D 高空俯瞰視角，具備高科技感與流暢動漫感。
- 街道與街廓必須與真實世界 Google Maps / OpenStreetMap 完全一致，道路折角、寬度、十字路口與路名嚴禁憑空捏造。

### 9. 🏪 連鎖商店三大法則：50% 剪裁 ✕ 嚴禁並排 ✕ 100% 真實經緯度 ✕ 連鎖效應
- **嚴禁商店並排（Strictly No Side-by-Side）**：超商/超市/手搖飲絕不可緊挨著連排成列，每間門市必須各自獨立座落於街角或街廓角落，保持物理間距（>= 38m，真實街距）。
- **50% 剪裁法則**：為避免網頁負擔過重，任何店家數量最多只能刪除一半（例如 500 間全家最多刪至 250 間；學府路一段 5 間全家最多刪 2 間留 3 間）。
- **真實經緯度**：留下來的每一間店家位置，必須跟真實世界 Google Maps / OSM 完全一模一樣。
- **連鎖效果**：超商具有連鎖機制（跨店集點、共通商品庫存、物流情報網絡）。
- **多元商店與市集**：納入 7-11、全家、萊爾富、OK、家樂福、全聯、CoCo 手搖飲、傳統市場（中山市場、城中市場、雙連市場、永樂市場、黃石市場等）與夜市（寧夏、湳雅、晴光等）。

### 10. 🚌 公車真實路線移動（TDX / OSM 站點軌跡，嚴禁死板來回）
- 公車不能只是一直在兩個端點之間死板來回移動！
- 必須遵循交通部 TDX / OpenStreetMap 的真實公車線形 Shape 節點與站牌序列行駛，行經真實轉角、專用道與路口。

### 11. 👻 天眼幽靈巡航視角（Ghost Drone View）與極速平移
- 當前階段角色人物與一般市民暫時隱形，玩家化為「天眼幽靈」在天空中俯瞰巡視大地圖。
- 游標拖曳平移反饋加速（1.35x 靈敏度），支援 WASD 巡航與 Shift 極速穿梭。

### 12. 📦 100% 免費地圖圖資與引擎工具生態系
- **已下載資料包**：使用者下載夾中備有 `taiwan-261009.osm.pbf`（約 312 MB），內含全台灣完整真實路網、建築多邊形外框、超商/地標 POI 經緯度與公車軌跡。
- **資料來源**：OpenStreetMap (OSM)、Geofabrik、Overpass Turbo、交通部 TDX、Overture Maps、政府資料開放平臺、TGOS。
- **渲染與開發套件**：MapLibre GL JS、Leaflet.js、OSMBuildings、PixiJS、Phaser 3、Three.js、QGIS、GeoJSON.io。

### 13. 🛑 「先不要做」原則（接手 AI 嚴守！）
- 使用者目前明確指示**「先不要做修改代碼」**，首要任務是做好規格記錄、技術調研與充分溝通。
- 任何接續的 AI Agent 在動手改動程式碼之前，**必須先向使用者提出規劃、確認方向，嚴禁擅自直接重寫或覆蓋代碼！**

## 🔄 四、 接續 AI 的 Review 與工作流程指南

當新的 AI Agent 取得此倉庫時，請遵循以下標準作業程序：

1. **環境檢查與啟動**：
   ```bash
   git status
   npm start # 啟動 local WebSocket 私服器與 HTTP (http://localhost:3000)
   ```
2. **語法與相容性檢查**：
   ```bash
   node -c game.js && node -c server.js
   ```
3. **驗證核心玩法運作**：
   - 開啟 `http://localhost:3000` 或 GitHub Pages。
   - 測試鍵盤 [WASD] 移動與按住 [Shift] / 點擊 `[🏃 奔跑]` 按鈕，確認流暢雙速奔跑。
   - 走至忠孝西路中央專用道，登上 307 幹線公車，測試高空空拍鳥瞰快轉過場動畫。
   - 走訪中山北路 CoCo 手搖飲與全家便利商店，確認門市外觀與購物流程。
   - 走訪北投分局調閱 4 分割 CCTV 監視器時序，出示 307 刷卡紀錄進行筆錄對質逮捕。
4. **程式碼修改與 Push 規範**：
   - 任何改動前請先執行語法檢查。
   - 完成修改後使用 git 提交並 push 至 `origin main`，GitHub Pages 會自動觸發部署。
   - 保持 `docs/` 內文件的最新更新。
5. **★ 每回合必做：改動必上 GitHub ✕ AI 交接指令必同步更新（委託人最高鐵則！）**：
   - 每次完成委託人下達的任何一個指令，**必須立即將所有修改內容 commit 並 push 至 GitHub 倉庫**！
   - 同時，**給其他 AI 的交接指令（`AI_HANDOFF_PROJECT_SPEC.md`、`AI_HANDOFF_COMPLETE_PROMPT.md`、`docs/` 與企劃書內的提示詞按鈕）也必須根據最新改動同步修改更新**！
   - 絕不可只改代碼而不推送到 GitHub，也不可漏掉更新交接指令！
